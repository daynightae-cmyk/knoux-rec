# مخطط مشروع KNOuX REC

**الإصدار الحالي للمخطط:** `1`  
**الامتداد:** `.knouxrec`  
**الموقع الافتراضي:** مجلد `projects/` ضمن بيانات التطبيق المحلية.

## الغرض

يمثل ملف المشروع تحريراً غير هدميّاً للتسجيل. لا يضم JSON أي فيديو أو WAV؛ بل يحتفظ فقط بمسارات الوسائط الأصلية وبيانات timeline والمظهر والتسميات. تنشئ العملية الرئيسية مشروعاً ذرياً عند إنهاء تسجيل صالح، وتحذف المشروع عندما يحذف المستخدم التسجيل من المكتبة.

| القسم | البيانات الفعلية |
|---|---|
| `media` | مرجع الفيديو النهائي ومرجع WAV النظامي إن وجد |
| `timeline` | مدة المصدر ونطاق قص مستمر اختياري واحد `startMs/endMs`؛ قائمة فارغة تعني المصدر كاملاً |
| `presentation` | نسبة الحشوة ولون الخلفية |
| `camera` | تمكين PiP والشكل والموضع والحجم والمرآة والشفافية |
| `captions` | لغة اختيارية ومقاطع ذات طوابع زمنية ونص |

## ضمانات الخدمة

تستخدم `desktop/project-service.cjs` كتابة atomically عبر ملف مؤقت ثم rename. يتحقق المخطط من نوع الحقول وحدود المدة، ويرفض نطاقات قص غير صحيحة أو أكثر من نطاق قص مستمر واحد، ويرفض timestamps غير صحيحة للتسميات وإصدار مخطط غير مدعوم. لا يتيح preload ملفات أو أوامر عامة؛ بل `project:get` و`project:save` وطلبات تصدير محددة فقط.

> ينفّذ الإصدار الحالي معاينة فيديو عبر بروتوكول محلي مقيد بمعرّف التسجيل، وقصاً مستمراً واحداً، وتحرير تسميات يدوي، وتصدير SRT، وتصدير MP4 يقرأ نطاق القص المحفوظ. لا يدعم بعد split/ripple أو قصاً متعدد المقاطع أو مسارات متعددة أو تضمين التسميات داخل الفيديو أو النسخ/الترجمة التلقائيين.
