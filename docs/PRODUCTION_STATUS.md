# حالة إنتاج KNOuX REC

هذا المستند يسجل **حالة الإثبات الحالية** فقط. لا تمثل الحالة `PASS` إلا بوجود الأدلة المذكورة؛ ولا يعني وجود واجهة أو اختبار بنيوي اكتمال سيناريو جهاز حقيقي.

| المجال | التنفيذ | الاختبار | التغليف | الحالة | الدليل والحدود |
|---|---:|---:|---:|---|---|
| تسجيل القرص التدريجي | نعم | نعم | سابقاً | PARTIAL | يكتب MediaRecorder دفعات إلى `.part` ثم إنهاء ذري؛ لا توجد قياسات جلسات 10/30/60 دقيقة. |
| صوت النظام WASAPI | نعم | بروتوكول/فحص بنيوي | سابقاً | PARTIAL | المساعد يلتقط WAV ويمرر FFmpeg دمجاً؛ لا توجد قياسات drift طويلة على أجهزة فعلية. |
| دمج الصوت النهائي | نعم | `test:ffmpeg` | تم فحص runtime سابقاً | PARTIAL | الاختبار يثبت WebM بصوت Opus؛ لا يثبت كل تركيبات جهاز النظام والميكروفون. |
| اختيار المنطقة وPiP | نعم | بنيوي | جزئي | PARTIAL | القص وPiP يمران عبر Canvas؛ لا يوجد E2E متعدد الشاشات/DPI أو كاميرا فعلية مسجلة. |
| استديو الصوت والكاميرا | نعم | نوع/بناء وبنيوي | لا | PARTIAL | عناصر التحكم تغيّر الكسب/الكتم/PiP عند بدء الجلسة؛ لا يوجد اختبار فصل جهاز. |
| مشروع `.knouxrec` | نعم | بنيوي و`test:project-export` | لا | PARTIAL | مخطط إصدار 1 وكتابة ذرية وIPC مقيد؛ تُحفظ لقطة الكاميرا ولوحة العرض بعد التسجيل، ولا توجد ترحيلات مخطط أو اختبار مشروع مستخدم كامل. |
| مجلة/استعادة جلسة | محدودة | بنيوي و`test:recovery` | لا | PARTIAL | تفحص واجهة Settings journals وتسترجع جزء WebM/MP4 متحققاً بلا sidecar WASAPI أو تحذفه؛ لا توجد force-kill E2E للتطبيق الفعلي ولا استعادة sidecar أو جزء غير قابل لفحص FFprobe. |
| تصدير MP4 | نعم | `test:export` و`test:project-export` | لا | PARTIAL | يولد MP4 فعلياً ويفحص FFprobe، ويقرأ نطاق القص المستمر المحفوظ؛ الناتج MPEG-4/AAC ضمن runtime الحالي، ولا توجد واجهة تقدم/إلغاء أو E2E بملف مستخدم. |
| المكتبة | أساسي | بنيوي | لا | PARTIAL | فتح/إظهار/حذف/تصدير ومدخل إلى محرر المشروع؛ البحث والفرز والفلاتر والصور المصغرة ما زالت غير مكتملة. |
| المحرر/الـtimeline | نعم، محدود | بنيوي و`test:project-export` | لا | PARTIAL | معاينة آمنة عبر بروتوكول محلي، scrub وundo/redo وقص مستمر واحد محفوظ ومطبق في MP4؛ لا split/ripple أو قص متعدد المقاطع أو E2E بوسيط مستخدم. |
| التسميات/النسخ/الترجمة | تسميات يدوية فقط | بنيوي و`test:caption-srt` | لا | PARTIAL | إدخال/تعديل/حذف مقاطع محفوظة وتصدير SRT ذرياً؛ النسخ والترجمة التلقائيان غير متاحين بوضوح، ولا يوجد تضمين للتسميات داخل الفيديو. |
| Smart Zoom/cursor/annotations | لا | لا | لا | NOT IMPLEMENTED | لا توجد بيانات تفاعل أصلية؛ لا يوجد ادعاء بوجودها. |
| اختبارات طويلة وAV drift | لا | لا | لا | NOT IMPLEMENTED | تتطلب جلسات حقيقية وقياساً محفوظاً. |
| installer وoffline E2E | جزئي | سابقاً | جزئي | PARTIAL | تغليف NSIS سابق موثق؛ لم يُعد اختباره بعد التغييرات الحالية. |

> لا يجوز دمج هذا الفرع في `main` أو وصفه بأنه إنتاجي قبل إغلاق حالات PARTIAL وNOT IMPLEMENTED وفق بوابات القبول في مواصفات المرحلة الثالثة.
