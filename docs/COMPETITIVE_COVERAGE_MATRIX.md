# معيار التغطية التنافسية لـ KNOuX REC

> لا تعد أي ميزة منفذة إلا بمسار خلفي حقيقي وحدود أمان وحالة خطأ واختبار قبول.

| المجال | حد السوق | الوضع الحالي | بوابة القبول |
|---|---|---|---|
| الالتقاط والصوت | شاشة/نافذة/منطقة وكاميرا وأجهزة وفلاتر | PARTIAL | جلسات طويلة وDPI/أجهزة/استعادة حقيقية |
| المكتبة | صور مصغرة وبحث وفرز وفلاتر ومشاريع | PARTIAL | صور حقيقية وبحث على مكتبة كبيرة وملفات مفقودة |
| المحرر | multi-cut/tracks/annotations/zoom/cursor | PARTIAL | export يستعمل timeline كاملاً واختبارات خرج |
| التسميات والوصول | نسخ وتحرير نصي وترجمة | PARTIAL | محرك مثبت وسياسة بيانات وقابلية تعطيل |
| الإنتاجية | hotkeys/tray/HUD/templates | PARTIAL | اختبارات اختصارات وتعطل وتجربة جهاز |
| التعاون | مشاركة وروابط وتعليقات وأدوار وتكاملات | NOT IMPLEMENTED | صلاحيات وانتهاء روابط وE2E وتدقيق |
| البث والمشاهد | scenes ومصادر متعددة وترميز | NOT IMPLEMENTED | بروتوكولات بث وقياس حمل |

## ترتيب التنفيذ

1. موثوقية الالتقاط والأجهزة والمساحة والاستعادة.
2. المكتبة والصور المصغرة والبحث.
3. timeline متعدد المقاطع والمسارات والتعليقات/المؤشر/Zoom.
4. الإنتاجية واللغات والذكاء بضوابط خصوصية.
5. التعاون والمشاركة الاختيارية.
6. البث المتقدم بعد إثبات التسجيل والتحرير.

## مراجع السوق

- [Camtasia](https://www.techsmith.com/camtasia/) — تسجيل متعدد المسارات وتحرير نصي وتسميات ومؤشر.
- [Loom](https://www.loom.com/) — مشاركة وتعليقات ومهام وتكاملات.
- [Loom AI](https://support.atlassian.com/loom/docs/loom-ai-features/) — فصول وتحرير بالنص وإزالة صمت ضمن حدود بيانات.
- [OBS Studio](https://obsproject.com/) — scenes ومزج وفلاتر واختصارات.
